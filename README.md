# cartec-videos

Serie audiovisual **CAR-TEC** de mecánica y electrónica avanzada, en formato vertical (Reels, TikTok y Shorts). Todo es motion graphics de dibujo técnico hecho con código en [Remotion](https://www.remotion.dev).

- **Sistema de diseño:** [`CARTEC_DESIGN_SYSTEM.md`](CARTEC_DESIGN_SYSTEM.md)
- **Flujo de producción:** [`CLAUDE.md`](CLAUDE.md)
- **Episodios:** [`docs/episodios/`](docs/episodios/)
- **Fotogramas y vídeos:** [`renders/`](renders/)

```bash
npm install
npx remotion studio
```
