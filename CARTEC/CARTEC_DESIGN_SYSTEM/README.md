# CARTEC_DESIGN_SYSTEM

El sistema de diseño de la serie no está en esta carpeta, sino en la raíz del repositorio, para que haya una sola versión:

- **[`CARTEC_DESIGN_SYSTEM.md`](../../CARTEC_DESIGN_SYSTEM.md):** reglas obligatorias (color, tipografía, retícula, zonas seguras, dibujo técnico, componentes, subtítulos, gráficas, movimiento, sonido y checklist).
- **[`src/system/tokens.ts`](../../src/system/tokens.ts):** los mismos valores en código. Es la fuente de verdad.
- **[`docs/referencia/referencia-estetica.webp`](../../docs/referencia/referencia-estetica.webp):** la imagen de referencia CPC.png. Solo estética, no datos.
- **Componentes y piezas:** `src/components/`, `src/draw/`, `src/parts/`, `src/charts/`.

Si un episodio necesita algo que el sistema no contempla, se propone en `CARTEC/PLAN_TEMPORADA_01.md` («Lo que los storyboards añaden al sistema») y solo se usa cuando lo apruebas. Después se documenta en `CARTEC_DESIGN_SYSTEM.md`.
