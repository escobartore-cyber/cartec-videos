# Locuciones y SRT

Sube aquí la locución y el SRT de cada episodio, tal cual salen de tu herramienta.

- **Nombre:** que empiece por el episodio, por ejemplo `EP04_voz.mp3` y `EP04.srt`. El resto del nombre da igual.
- **Formato:** MP3 o WAV para la voz; SRT para los subtítulos.
- **Desde el móvil:** abre esta carpeta en el navegador (la app de GitHub no permite subir archivos), pulsa **Add file → Upload files**, elige los archivos y pulsa **Commit changes**.
- También puedes adjuntarlos en el chat de Claude como hasta ahora; acaban aquí igual.

Lo que llega aquí es el original. Yo corrijo el SRT contra el guion y paso la voz y el SRT corregido a `public/episodes/NN-tema/`, que es de donde los lee el vídeo.
